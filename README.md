# 链接岛 · LinkIsland

一款 Android 链接跳转工具。复制网页链接后，链接岛会按本地规则识别目标应用，通过通知提示是否打开；支持的 Xiaomi / HyperOS 设备可使用原生超级岛展示。

## 功能

- **复制识别**：支持 Shizuku 和 Root 两种监听方式，结合复制事件与两秒兜底检查。
- **规则跳转**：按域名、关键词或正则表达式匹配，支持目标应用选择和链接改写；按列表顺序使用第一条命中的规则，点击“排序”进入编辑状态后可拖动调整优先级，普通列表隐藏手柄。
- **命中预览与冲突提醒**：在链接测试页查看实际匹配顺序、优先规则、目标应用状态和改写结果；规则列表提醒通用规则遮挡及相同条件重复。预览不发通知、不跳转、不联网。
- **配置备份**：通过系统文件选择器导出规则与普通设置，导入前预览并选择合并或覆盖，支持 Debug／Release 之间迁移配置。
- **常用预设**：内置 GitHub、哔哩哔哩、知乎、小红书、抖音、微博、淘宝／天猫、京东、拼多多、酷安、豆瓣、网易云音乐、YouTube、阿里云盘、百度网盘、蓝奏云（普通版与优享版）、123 云盘、夸克网盘、天翼云盘、迅雷和 115 网盘规则。
- **浏览器选择**：通过明确的浏览器规则打开网页，可跟随系统默认、指定已安装浏览器或每次询问；没有规则命中时不提示、不跳转。
- **跳转日志**：从首页查看最近 100 次识别记录；同一次复制的匹配、提示、点击与跳转合并展示，点击展开完整过程，支持仅看失败和清空。展开记录可编辑命中规则，或按域名新建规则；排序和改名后仍可定位，原规则已变更、删除或重复时不会猜测编辑目标。
- **提示时长**：可选择 5、10、15 或 30 秒后自动移除链接提示，默认 30 秒。
- **防误清除**：链接提示请求保留在“一键清除”之后，仍可通过打开、忽略或自动超时移除；具体展示由系统决定。
- **临时暂停**：首页可暂停链接提示 5、15 或 60 分钟，到期自动继续，也可提前恢复；暂停期间保留授权连接和自动恢复检测，不补发暂停期间的链接。控制中心可添加“链接岛”磁贴，点按暂停 15 分钟或立即继续。手动关闭监听后不自动开启。
- **监听恢复**：已开启的监听可在重新打开应用、授权桥断线或心跳超时后恢复；手动停止后不自行开启。
- **独立管理页**：设置中提供运行诊断与授权管理入口，跳转日志从首页进入。

## 使用方式

1. 安装应用并允许通知，在系统通知设置中按需开启悬浮提示。
2. 进入设置，选择 Shizuku 或 Root。Shizuku 模式需要先启动 Shizuku 服务；Root 模式需要设备已获得 Root 并允许应用授权。
3. 返回首页开启监听，在其他应用中复制 HTTP／HTTPS 链接。
4. 点击提示中的“打开”，进入目标应用；目标无法处理时，可选择改用浏览器。
5. 在“匹配规则”中调整规则；在设置中选择浏览器、提示停留时间，并查看诊断或日志。

浏览器也是一条可编辑、停用、删除和排序的规则，默认位于末尾，匹配 HTTP／HTTPS 链接。停用或删除它后，其他规则也未命中的链接不发提示、不跳转。蓝奏云普通分享链接默认使用所选浏览器，优享版链接使用对应 App；可在规则中修改目标应用。新建规则默认插在通用浏览器规则之前。

“链接测试”可先预览规则命中结果，再按需发送提示，无需先开启剪贴板监听。

在“设置 → 备份与恢复”中导出或选择备份文件。合并时保留本机相同匹配方式和匹配内容的规则，新规则追加到末尾，并应用备份中的普通设置；覆盖时使用备份替换规则与普通设置。导入后需检查授权并手动重新开启监听。

## 自定义规则

编辑页顶部统一选择网站、关键词、所有网页或正则表达式，再填写对应条件、搜索选择目标应用。规则名称可留空自动生成。

| 识别方式 | 填写示例 |
| --- | --- |
| 来自某些网站 | 填写 `github.com`，也可直接粘贴 `https://github.com/owner/repo`；多个网站用逗号或换行分开 |
| 链接中包含关键词 | 填写 `/video/` 等普通文字，不区分大小写 |
| 所有网页链接 | 无需填写匹配内容，匹配 HTTP／HTTPS 网页，建议放在列表末尾 |
| 正则表达式 | 选择后在下方填写 Java 正则表达式 |

网站模式可选择是否识别子域名，例如 `example.com` 是否同时包含 `m.example.com`。目标应用通过名称或包名搜索选择，选择网页浏览器时使用设置中的浏览器；默认打开原链接。

“高级设置”提供手动填写包名和链接改写；正则与其他匹配方式统一放在顶部选择。已有网站预设以可读的网站列表展示，复杂自定义正则保持高级模式。底层沿用原有规则格式，旧规则、排序和备份继续兼容。已解析规则与正则在进程内缓存，编辑、排序、停用、删除或导入后，下次识别立即使用新配置。

应用必须支持对应链接或公开协议。预设规则不会保证第三方应用的所有页面都可直接打开。

## 隐私

链接识别和规则匹配在本机完成，不保存剪贴板正文或完整链接历史。系统标记为敏感的剪贴板内容会跳过。

跳转日志仅在本机保留最近 100 次识别的时间、域名、规则与处理结果，以及用于定位命中规则的摘要标识，不保存链接路径、查询参数或剪贴板正文，可在应用内清空。失败筛选按最后处理状态显示；跳过、忽略和正常超时不作为失败。旧版日志保留为独立历史记录，新记录按复制次数合并。

备份是明文 JSON，包含自定义规则与普通设置，不包含系统授权、监听运行状态、跳转日志或剪贴板正文。自定义规则的匹配内容和链接模板也会包含在文件中，请选择合适的保存位置。

仅当用户点击、已安装的小红书无法直接处理分享短链时，应用才会访问指定的小红书 HTTPS 域名解析跳转；不请求笔记正文，不使用第三方解析服务。

## 兼容性

- 最低 Android 12；后台读取需要可用的 Shizuku 或 Root 授权。
- 超级岛展示由设备、HyperOS 版本及系统授权决定，不支持的设备使用普通通知。
- 系统强行停止和手机重启后需要手动开启监听；Shizuku 服务也需保持可用。
- 系统省电策略可能限制后台运行，可在授权管理页检查相关设置。

## 下载与构建

从 [GitHub Actions](https://github.com/Mo-SeTian/LinkIsland/actions) 获取构建产物。每次构建包含 Debug 和 Release；Debug 包名带 `.debug`，可与 Release 共存。文件名末尾为 APK 的 MD5 前 8 位，产物中另附完整 SHA-256 校验值。

源码使用 Kotlin、Java、Jetpack Compose 和 miuix，权限桥接基于 Shizuku API 与 libsu。构建环境为 JDK 17、Android SDK 36。

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

第三方依赖及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
